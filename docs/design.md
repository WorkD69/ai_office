# Дизайн v2

Обязателен для всех экранов офиса. Источник продукта — [спека](spec.md), графика — [ADR 0004](adr/0004-pixel-agents-art.md).
Утверждён владельцем 2026-11-25 по макетам 390 и 1440 px (#3).

## Тон

Тёмный уютный пиксельный офис, на который смотришь сверху. Сцена — главное, интерфейс вокруг неё
спокойный и плоский. Всё на простом русском (демо для посетителей — на английском). Сначала видно,
кто работает и кто ждёт тебя, детали — по тапу.

## Палитра

Токены уже живут в `apps/web/src/styles.css`; новые цвета добавляются туда же, компоненты пишут
только `var(--…)`.

| Токен         | Hex                               | Где                                      |
| ------------- | --------------------------------- | ---------------------------------------- |
| `--bg`        | `#14121c`                         | фон страницы и пустые места вокруг офиса |
| `--surface`   | `#1d1a29`                         | панели, нижний лист, вкладки             |
| `--surface-2` | смесь `--text` 7 % и `--surface`  | строки списков, плитки                   |
| `--border`    | смесь `--text` 18 % и `--surface` | рамки 2 px                               |
| `--text`      | `#ece6d8`                         | основной текст                           |
| `--muted`     | `#9b93ab`                         | подписи, время                           |
| `--accent`    | `#f2b84b`                         | фокус, активная вкладка, «ждёт тебя»     |
| `--ok`        | `#6cd46c`                         | работает                                 |
| `--warn`      | `#ffd24a`                         | ждёт тебя                                |
| `--info`      | `#79bcff`                         | ждёт внешний сервис                      |
| `--bad`       | `#ff5a5f`                         | ошибка                                   |
| `--idle`      | `#b9b2c6`                         | нет задач                                |

Цвета сцены (полы, стены, мебель) берутся из спрайтов Pixel Agents и в токены не выносятся.
Цвет комнаты — только акцент таблички с её названием.

## Типографика

- Текст: системный sans (`--font`), 14/1.4 на телефоне, 14/1.4 на ноуте.
- Заголовки секций: 12 px, верхний регистр, разрядка 0.12em, `--muted`, квадратик-маркер `--accent`.
- Цифры счётчиков: 20 px, жирный, табличные цифры.
- Подписи в сцене (табличка, название комнаты): 10–11 px, жирный, на подложке; рисуются в DOM
  поверх canvas, а не в canvas, чтобы кириллица была чёткой.

## Отступы, углы, тени

- Шаг 4 px: 4, 8, 12, 16, 24.
- Углы прямые (radius 0), рамки 2 px, жёсткая тень `2px 2px 0 var(--shadow)` без размытия.
- Касаемые элементы не меньше 44×44 px.

## Сцена

- Тайл 16 px, персонаж 16×32, вид сверху 3/4 (графика Pixel Agents).
- Масштаб только целый (1×, 2×, 3× логического пикселя), сглаживание выключено.
- Комната: стена 2 тайла сверху (полки, часы, картины, окна), пол — свой у каждого типа комнаты
  (дерево, плитка, ковёр), между комнатами тёмная стена.
- Стол агента: стол, компьютер, стул, персонаж за ним спиной к зрителю. Пустых «будущих» столов нет.
- Высота комнаты — по числу столов. На телефоне комната в полэкрана вмещает 1 стол в ряд,
  комната на всю ширину — 2. Декоративных зон без столов
  (диваны, кофейный угол) на телефоне нет, на ноуте — только если остаётся место.
- Комнаты «Сервисы» (обычные боты, стойки серверов) и «Новенькие» (агенты без паспорта, этап 2) —
  обычные комнаты со своей мебелью.

### Статусы на сцене

| Статус              | Персонаж и монитор                                                              | Значок над головой                  |
| ------------------- | ------------------------------------------------------------------------------- | ----------------------------------- |
| работает            | сидит, монитор светится и мигает (3 кадра)                                      | зелёная точка                       |
| ждёт тебя           | поднятая рука (свой кадр 16×32 в стиле Pixel Agents, не палочка поверх спрайта) | облачко «!» `--warn`                |
| ждёт внешний сервис | сидит, монитор светится                                                         | облачко с песочными часами `--info` |
| ошибка              | сидит, монитор красный                                                          | облачко «×» `--bad`                 |
| нет задач           | сидит, монитор светится без мигания                                             | нет                                 |
| не на связи         | стул пустой, монитор погашен                                                    | нет, табличка `--off`               |

Упавшая задача по расписанию не меняет вид агента — это отдельный пункт «требует тебя».

### Табличка «чем занят»

Под столом, одна строка: точка статуса + имя. Имя режется по ширине таблички, а не по числу
символов; хвост вида «#2» сохраняется («Claude Co… #2»), чтобы одинаковые имена различались. Тап по столу открывает
карточку. Свободный текст Hermes на табличку не попадает — он в карточке под «подробнее»
(#6). На ноуте при наведении — подсказка со статусом по-русски.

## Телефон (390 px)

```
+------------------------------------+
| AI Office   9 агентов · ждут 3   (!)|  шапка 44 px, одна строка
+------------------------------------+
| +---------------+ +---------------+ |
| | стена/полки   | | стена/окно    | |
| | пол  [стол]   | | пол  [стол]   | |  офис: комнаты в 2 колонки
| |  • Коорд.     | |  • Охотник    | |  по ширине экрана, листается
| +---------------+ +---------------+ |  только вниз
| +---------------+ +---------------+ |
| |   ...         | |   ...         | |
+------------------------------------+
|  Офис  |  Команда  |  Сводка (3)   |  нижние вкладки 56 px + safe area
+------------------------------------+
```

- Прокрутки вбок нет никогда. Масштаб сцены — наибольший целый, при котором 2 колонки влезают
  в ширину; если комнат больше, чем влезает по высоте, офис листается вниз.
- Шапка: название, «N агентов», «ждут тебя N» (`--warn`, тап → вкладка «Сводка»).
- Плашка «демо-данные» в демо остаётся над шапкой.
- Вкладка «Команда» — список карточек; «Сводка» — по порядку: требует тебя → квоты → лента →
  сервер и «Сервисы».

### Карточка агента — нижний лист

- Открывается снизу, высота по содержимому, но не больше 85 % экрана; ручка сверху, закрывается свайпом вниз или тапом вне.
- Порядок: имя + статус по-русски → одна строка «что делает» (описание) → кнопка «Открыть чат»
  (во всю ширину, `--accent`) → последний и следующий запуск → расход этого агента за день и неделю →
  2–3 своих счётчика → «подробнее» (свёрнуто: текст Hermes, модель, токены, технические причины).
- Пустые поля не показываются, а не рисуются прочерком.
- Квота в карточке — доля конкретного агента за день и неделю. Общие окна провайдера
  («5 часов», «неделя») показываются только в «Сводке».

## Ноут (1440 px)

```
+-----------------------------------------------+----------------+
|                                               | AI Office      |
|   офис крупно, на всю высоту окна             | 9 · 6 · ждут 3 |
|   комнаты в 3 колонки, целый масштаб (3×)     +----------------+
|                                               | Требует тебя   |
|                                               | Квоты          |
|                                               | Лента          |
|                                               | Сервер         |
+-----------------------------------------------+----------------+
                                                  панель 392 px
```

- Масштаб — наибольший целый, при котором офис влезает в ширину и высоту области (на 1440×900
  это 3×); если не влезает при 2×, офис листается вниз.
- Карточка агента на ноуте открывается в правой панели поверх «Сводки», кнопка «назад».
- Вкладок внизу нет: всё, что на телефоне во вкладках, — в панели.

## Движение

| Слой  | Что                                    | Длительность, кривая             |
| ----- | -------------------------------------- | -------------------------------- |
| покой | мигание монитора у работающих, 3 кадра | 400 мс на кадр                   |
| покой | поднятая рука покачивается             | 600 мс, туда-обратно             |
| покой | облачко «!» мягко подпрыгивает на 1 px | 800 мс                           |
| тап   | нижний лист выезжает / уезжает         | 200 / 160 мс, ease-out / ease-in |
| тап   | переключение вкладок                   | без анимации                     |

- Цикл отрисовки ≤ 30 кадров/с, пауза на скрытой вкладке (ADR 0002).
- `prefers-reduced-motion`: монитор и рука статичны, лист появляется без сдвига.

## Не на этапе 1

Ходьба персонажей, анимации «печатает / читает / кофе», день и ночь, табло итогов дня, субагенты
за спиной, звуки.

## Доступность

Контраст текста не ниже 4.5:1, видимый фокус (`--accent`, 2 px), касаемые элементы ≥ 44 px,
у значков статуса есть текст (подсказка / `aria-label`), цвет не единственный признак статуса.
